# Personal AI Agent Desktop

A local-first Tauri desktop client for the existing Python task manager and Google Calendar integration. The React frontend runs in Tauri and communicates with a loopback-only FastAPI server.

## Structure

- `main.py` - task storage, Google Calendar, and local planner logic
- `api.py` - FastAPI loopback API on `127.0.0.1:8787`
- `frontend/` - React, TypeScript, and Vite application
- `frontend/src-tauri/` - Tauri 2 desktop shell
- `test_api.py` - focused API tests

`tasks.json`, `tasks_backup.json`, and any existing credential files are left as local application data and are not generated by setup.

## Prerequisites

- Python 3.11 or newer
- Node.js 20 or newer
- Rust and platform Tauri prerequisites

## Backend setup

Windows (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python api.py
```

The API is available only at `http://127.0.0.1:8787`. Google Calendar remains optional; task management works locally without calendar credentials.

## Frontend

In a second terminal:

```powershell
npm install --prefix frontend
npm run frontend:dev
```

For the desktop shell, keep the API running and use:

```powershell
npm run tauri:dev
```

Build the frontend or desktop bundle with:

```powershell
npm run frontend:build
npm run tauri:build
```

## Tests

```powershell
.\.venv\Scripts\python -m unittest test_api.py
```
